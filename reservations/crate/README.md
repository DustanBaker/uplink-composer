# bootwright

Builds customized Windows and Linux OS install media: debloated installs,
local-account-only setup, and driver injection.

**This crate is a placeholder.** The name is reserved while the tool is being
built; there is no functionality here yet. Follow the work at
<https://github.com/uplinkresearch/bootwright>.

Bootwright is a standalone tool — it writes its own bootable media rather than
layering on another loader.
